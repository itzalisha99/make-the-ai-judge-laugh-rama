One funny line about office life, written to `/output/entry.txt`:

> We moved to an open-plan office so we could collaborate. Now we all wear headphones and message each other.

## Run

```sh
python3 main.py
```

Standard library only. The program validates the line against the bounty gate (UTF-8, 1–200 characters, one line, no control characters) and reads the file back to confirm it is byte-for-byte what was intended.
